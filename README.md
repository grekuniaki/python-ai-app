# AI文章作成アシスタント

Gemini API を搭載した個人用ライティングツール。7つの便利なAI機能であなたの執筆をサポートします。ログイン不要、データベース不要の個人用アプリです。

## 🎯 機能一覧

1. **📧 メール返信文生成** - 受信メールに対する返信文をAIが生成
2. **📝 文章要約** - 長い文章を指定した長さで要約
3. **✍️ ブログ記事執筆** - テーマからブログ記事を執筆
4. **📱 SNS投稿生成** - プラットフォーム最適化で投稿を生成
5. **🔄 トーン・スタイル変換** - 同じ内容を異なる文体で書き換え
6. **✅ 文章校正** - 誤字脱字・文法を修正・改善
7. **🌐 翻訳** - 複数言語への自動翻訳

## 📋 前提条件

- Python 3.10 以上
- Google Gemini API キー（[Google AI Studio](https://aistudio.google.com/apikey) で無料取得可能）

## 🚀 セットアップ

### 1. 仮想環境を作成

```bash
python -m venv venv
```

### 2. 仮想環境を有効化

**Windows:**
```bash
venv\Scripts\activate
```

**macOS/Linux:**
```bash
source venv/bin/activate
```

### 3. 依存パッケージをインストール

```bash
pip install -r requirements.txt
```

### 4. 環境変数を設定

`.env.example` を `.env` にコピーし、取得した Gemini API キーを設定してください。

```bash
# Windows
copy .env.example .env

# macOS/Linux
cp .env.example .env
```

`.env` ファイルを開いて、`GEMINI_API_KEY` に API キーを入力してください。

```
GEMINI_API_KEY=your_actual_api_key_here
GEMINI_MODEL=gemini-2.5-flash
```

### 5. アプリを起動

```bash
streamlit run app.py
```

ブラウザが自動的に開きます。開かない場合は、ターミナルに表示されたURLにアクセスしてください（通常は `http://localhost:8501`）。

## 📖 使い方

1. **アプリ起動** - `streamlit run app.py` を実行
2. **機能を選択** - 左側のサイドバーから使いたい機能をクリック
3. **入力を入力** - 指定されたテキストボックスに入力内容を入力
4. **生成をクリック** - 「生成する」ボタンをクリック
5. **結果を確認** - 数秒でAIが処理を行い、結果が表示されます

### 各機能の詳細

#### 📧 メール返信文生成
受信メール本文、盛り込みたいポイント、返信のトーン、署名（任意）を入力すると、AIが適切な返信文を生成します。

#### 📝 文章要約
要約したい文章、要約の長さ（短め/普通/詳しめ）、出力スタイル（文章形式/箇条書き）を選択して生成します。

#### ✍️ ブログ記事執筆
トピック、ターゲット読者、トーン、文字数目安、要点を入力すると、ブログ記事をMarkdown形式で生成します。

#### 📱 SNS投稿生成
投稿内容、プラットフォーム（X/Instagram/LinkedIn）、トーンを選択すると、プラットフォーム最適化された投稿文を生成します。ハッシュタグ候補も表示されます。

#### 🔄 トーン・スタイル変換
変換したい文章と複数の変換先トーンを選択すると、各トーンでの書き換え版が表示されます。

#### ✅ 文章校正
校正したい文章を入力すると、誤字脱字・文法エラー・不自然な言い回しを修正します。読みやすさフィードバックもオプションで表示可能です。

#### 🌐 翻訳
翻訳したい文章と翻訳先言語を選択すると、AIが自動検出した元言語から指定言語への翻訳を行います。

## ⚙️ 設定

### GEMINI_MODEL の変更
`.env` ファイルの `GEMINI_MODEL` を変更することで、使用するGeminiモデルを変更できます。

```
GEMINI_MODEL=gemini-2.0-flash
```

**⚠️ 注意：** `.env` ファイル変更後は、Streamlit アプリを完全に再起動してください（ブラウザの再読み込みだけでは不十分です）。ターミナルで `Ctrl+C` を押してアプリを停止し、再度 `streamlit run app.py` を実行してください。

## 🐛 トラブルシューティング

### 「設定エラー: GEMINI_API_KEY が設定されていません」

- `.env` ファイルが存在することを確認してください
- `GEMINI_API_KEY` にAPIキーが正しく設定されていることを確認してください
- `.env` ファイルを編集した場合は、Streamlitアプリを再起動してください

### 「Gemini APIエラー」

- ネットワーク接続を確認してください
- APIキーが有効であることを確認してください（Google AI Studioで確認可能）
- APIの利用制限に達していないか確認してください
- ブラウザのコンソール（F12キーで開く）でエラーメッセージを確認してください

### アプリが遅い、または反応しない

- ネットワーク接続が安定していることを確認してください
- Gemini APIの負荷状況を確認してください
- ブラウザのキャッシュをクリアしてから再度試してください

## 📝 注意事項

- このアプリは個人用です。ログイン機能やデータ保存機能はありません
- 生成結果はブラウザのセッション内でのみ保持されます。ページを更新すると消えます
- 結果をコピー＆ペーストして、他のアプリケーション（テキストエディタ、メール、SNS等）で使用してください
- Gemini APIの利用には[Google AI Studio](https://aistudio.google.com/apikey)での登録と、API キーの取得が必要です
